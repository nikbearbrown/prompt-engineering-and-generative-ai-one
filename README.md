# Prompt Engineering and Generative AI (AI Plus One)

## About the book

This nine-chapter rough draft teaches readers who write, test or supervise generative workflows to turn vague tasks into checkable instructions. You will specify the task, ground an answer in fixed evidence, set boundaries for tool use, and diagnose failures in retrieval, context or evaluation. No model account is needed; optional labs use Python 3.9 or newer.

## How to teach or study it

Work the [first-attempt sheet](activity/FIRST-ATTEMPT.md) before opening the examples. The [Part I guide](PART-I.md) builds from one task through grounding, authorization and tests. The [Part II guide](PART-II.md) keeps the benchmark fixed while changing audience, context, optimization and input modality. Defend one decision in the [capstone](activity/CAPSTONE.md), then apply the approach to three new records in the [transfer exercise](activity/TRANSFER.md). Responses are authored or simulated, not live model benchmark results.

# Take-home capstone: defend one decision

Design a reading assistant for a fictional repair desk. It should tell someone whether an item is eligible for assessment using a small set of invented policy records. It may draft a recommendation, never send it or make a booking.

## Phase gates

1. **First attempt without AI.** Write the contract, resolve a case by hand, and set correctness and abstention criteria. Hold two cases out. Record a prediction for a known failure.
2. **Bounded comparison.** Run both versions under the same visible settings with synthetic data only, if you have access to a permitted text model. Use no credentials in your hand-in, no personal data, no purchases and no action tools. If no model is available, compare two clearly marked synthetic candidate sets. Do not claim model performance on the offline track.
3. **Independent evidence check.** Before consulting another model, examine each consequential decision and cite the exact applicable clause. Calculate any quantities yourself. Record which part of the work you accept, reject, or revise, and why. Retain disagreements instead of hiding them.
4. **Unaided transfer.** Ask a peer or instructor to release one new synthetic case after the first hand-in. Explain the decision aloud or in a short in-person note without a model, including what would change it. The activity is a suggested assessment, not a claim that this method prevents substitution.

## What to submit

Keep a short process log with timestamp, version, first prediction, proposed answer, source evidence, independent check, revision, and reason. If using a model, disclose the visible model and settings, the exact prompt parts you changed, and which outputs you excluded. Preserve your first attempt. If using only fixtures, declare that. Do not award credit for merely naming a tool.

Suggested rubric (0–2 each, ordinal criteria; add only if useful locally):

| Criterion | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Independent frame | Missing | Partial | Prior contract, deciding evidence and falsifiable prediction |
| Controlled comparison | Ungradable | Both versions but a changed test or missing outcome | Same panel and fixed scorer, with failure counts |
| Evidence audit | Unsupported | Mostly appropriate but misses an authority, unit, or uncertainty | Each consequential claim checked against applicable source |
| Read-only boundary | Unclear or unsafe | Draft limit stated but not demonstrated | Independent check of incapable or blocked action and replay case |
| Transfer and process trace | Missing | One is incomplete | Unaided new case justified and log distinguishes model from human work |

An instructor chooses accommodations, privacy practices, and local assessment rules. This file does not install an LMS course or represent institutional policy.

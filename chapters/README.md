# Prompt Engineering and Generative AI (AI Plus One): chapter guide

[Return to the book overview](../README.md).

### Part I · Build a checkable workflow

1. [Describe the task before writing prompts](../chapters/01-describe-the-task.md): Turn a vague request into a task with a purpose, evidence and acceptance checks.
2. [Compare prompt patterns on the same job](../chapters/02-compare-prompt-patterns.md): Compare prompt patterns without changing the underlying work.
3. [Ground answers in evidence](../chapters/03-ground-answers.md): Separate what a source supports from what the model merely asserts.
4. [Bound what a tool-using agent may do](../chapters/04-bound-agent-actions.md): Specify tool permissions and the conditions for stopping or asking.
5. [Build a repeatable prompt evaluation](../chapters/05-repeatable-evaluation.md): Freeze evaluation cases and make failures repeatable.

### Part II · Diagnose harder cases

6. [Diagnose audience, role, and evidence separately](../chapters/06-diagnose-audience-and-prompt.md): Distinguish role, reader and evidence requirements in a disputed answer.
7. [Measure whether context can do its job](../chapters/07-measure-context-use.md): Test whether a model can use evidence in different context positions.
8. [Optimize against a fixed test](../chapters/08-optimize-against-a-fixed-test.md): Compare candidate changes on a fixed evaluation and protect a holdout.
9. [Operate multimodal workflows](../chapters/09-operate-multimodal-workflows.md): Trace evidence and check handoffs across text, images and other inputs.
